# My Web 交接
先读本文件及用户的新要求即可，不需要重新阅读历史对话。

## 运行
安装 Node.js（建议 22.12 或更新版）。进入解压后的 My Web 目录，执行：
```
npm ci
npm run dev
```
打开终端显示的本地地址。macOS 可双击打开网站.command。
不要直接以 file:// 打开 index.html。

## 文件定位
- index.html：开场黄色方块波浪、黑 F 放大开窗、现有中英文和作品区。
- hero.css：排版和图层；最末段为最新参考图字体比例覆盖规则。
- hero.js：滚轮驱动英文离场、镜片扩大显示中文、作品区进入。
- HeroFluidGlass.jsx：镜片；中文随扩大衔接到原生 DOM 保持清晰。
- ShapeWaves.jsx / app-components.jsx：黄色几何背景及参数；入口末尾按参考图校正英文四行宽度。
- NavigationWheel.jsx / .css：按钮、遮罩、菜单分类和跳转。
- OptionWheel.jsx / .css：React Bits 轮盘，添加 onActivate 支持点击中央项或 Enter 跳转。
- public/fonts：DINish 和思源宋体字体，均已携带。
- references：最新排版和轮盘参考图。
